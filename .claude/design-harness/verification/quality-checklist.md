# 品質チェックリスト（作業用）

## A. 事実性チェック
- [ ] 店舗雰囲気・人間関係・まかない・シフト情報は実態確認済みか
- [ ] 誇張や断定語が含まれていないか
- [ ] 条件表現（時給/勤務条件）が誤解を招かないか

## B. ブランド/トーンチェック
- [ ] フレンドリーかつ丁寧なトーンになっているか
- [ ] 不安を煽る言い回しを使っていないか
- [ ] 「安心して応募できる」文脈が伝わるか

## C. クリエイティブ構造チェック
- [ ] 1画面1メッセージになっているか
- [ ] 求人票にないリアル要素が最低1つ以上含まれるか
- [ ] 視線導線に沿ってCTAが配置されているか

## D. 導線チェック
- [ ] 投稿からフォロー誘導が明確か
- [ ] リール視聴の誘導文があるか
- [ ] 最終応募導線が理解できるか

## E. 成果チェック（公開後）
- [ ] フォロー率
- [ ] リール遷移率
- [ ] 応募遷移率
- [ ] コメント/DMの安心感に関する反応
