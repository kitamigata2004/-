# 利用シーン（媒体 × 目的）

## 1. Instagramフィード投稿 × 認知拡大
- 目的: 「バイト探偵」を知ってもらう
- 訴求: 求人票では見えないリアル（雰囲気・人間関係・まかない）
- CTA: アカウントをフォロー

## 2. Instagramフィード投稿 × リール誘導
- 目的: 動画視聴で理解を深める
- 訴求: 「1枚では伝わらない現場の空気はリールへ」
- CTA: リール動画を見る

## 3. リール視聴後導線 × 応募転換
- 目的: 応募アクションに繋げる
- 訴求: シフト柔軟性、未経験歓迎、スタッフの実感コメント
- CTA: プロフィールリンク/応募導線へ

## 4. LP画像（投稿用クリエイティブ） × 一連導線の要約
- 目的: 投稿→フォロー→リール→応募の流れを可視化
- 訴求: 「応募前にリアルが分かる安心感」
- CTA: 今すぐフォローして最新リールをチェック
