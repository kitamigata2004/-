# 設計原則（詳細版）

1. **不安先回り原則**
   - 初バイト層が応募前に抱える不安（雰囲気・人間関係・シフト）を先に提示し、解消情報を隣接配置する。

2. **リアル可視化原則**
   - 求人票テキストより、現場のリアル情報（写真・短文コメント・具体シーン）を主情報として扱う。

3. **導線連結原則**
   - 1投稿のゴールは応募完了ではなく、次の行動（フォロー→リール）へ確実に接続すること。

4. **誠実コミュニケーション原則**
   - 若年層向けでも誇張しない。実態ベースで安心感を作る。

5. **モバイル即読原則**
   - スマホで3秒以内に主メッセージを理解できる情報密度に制御する。
