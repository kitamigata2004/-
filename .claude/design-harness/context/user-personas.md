# ユーザーペルソナ

## ペルソナA: 初バイト高校生
- 基本属性: 16-18歳 / 高校生 / 初めてのアルバイト探し
- 抱えている悩み: 学校との両立、怖い先輩がいないか、未経験でも大丈夫か
- デザインに期待すること: 写真や体験談で職場の雰囲気が分かること
- 感じてほしい印象: 「ここなら安心して始められそう」

## ペルソナB: 大学生（バイト経験浅め）
- 基本属性: 18-22歳 / 大学生 / 学業と両立できるバイトを探している
- 抱えている悩み: シフトの柔軟さ、テスト期間配慮、同年代がいるか
- デザインに期待すること: シフト例・1日の流れ・スタッフのリアル
- 感じてほしい印象: 「働く自分を具体的に想像できる」

## ペルソナC: フリーター・専門学生
- 基本属性: 18-25歳 / 専門学生・フリーター
- 抱えている悩み: 収入安定、職場の人間関係、継続しやすさ
- デザインに期待すること: 現場の空気、定着しやすさ、待遇の透明性
- 感じてほしい印象: 「長く続けられる職場か判断できる」
